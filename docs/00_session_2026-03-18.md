## Key Technical Learnings This Session
- `useInView` `margin` maps to IntersectionObserver `rootMargin` — changing hero height can break downstream component animations
- Inline `style={{}}` bypasses Tailwind's responsive system — always use Tailwind classes for responsive sizing
- `absolute` positioning is relative to nearest positioned ancestor — caused the scroll arrow bug
- `inline-flex` without `flex-wrap` causes horizontal overflow on mobile
- For a static content site, `npm run build` + visual inspection is sufficient — unit tests are overkill
